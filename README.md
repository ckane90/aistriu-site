# aistriu-site

The public holding page for Aistriú Health, served by GitHub Pages at aistriuhealth.com.

- `index.html` is the whole site: one self-contained page (styles and script inline, fonts from Google Fonts).
- `.nojekyll` tells GitHub Pages to serve the files as they are.

To change the page, edit `index.html` and push to `main`. The site updates within a minute or two.
